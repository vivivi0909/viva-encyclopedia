# VIVA 대규모 도감 조사 기록

확인일: 2026-11-05. 온라인 GitHub 공개 검색 및 공개 저장소의 파일을 읽고 학명·분류·기초 사육/재배 사실을 정리했습니다. 정확한 원자료 커밋은 `sources.json`에 고정했습니다. 원자료에 없는 값을 추정해 넣지 않았습니다.

기존 상세 항목은 같은 학명의 추가 항목과 합쳐 식별자를 유지했습니다. 비바리움 3유형은 위 종 수에서 제외했습니다. 생물 845종 + 비바리움 3유형 = 848개 항목입니다. 학명의 완전 일치 중복을 제거했으며 확인된 이명은 현재 명칭으로 통합하거나 제외했습니다. 원자료 자체에 남은 분류학적 이명 가능성까지 완전히 감수했다는 의미는 아닙니다.

## 조사·선정 방법

- 파충류: `reptile-candidates.txt`의 취미 사육 후보를 공개 Reptile Database / iNaturalist 내보내기 자료의 학명과 대조했습니다. 도마뱀·뱀·거북의 분류와 원산지 사실, 원 종별 링크를 보존했습니다. 일치하지 않는 명칭은 수록하지 않았습니다. 이 절차는 293종 모두의 현재 사육 허가·국내 유통·최적 사육 수치가 검증되었다는 뜻이 아닙니다.
- 양서류: Connelly 등(2023)의 미국 수입 연구에서 `description=LIV`, `purpose=T`, `source=C/F`인 생체·사육 원산 상업 거래 기록만 집계했습니다. 이는 거래 신고 코드이며 특정 번식 성과나 현행 국내 합법성 증거는 아닙니다. AmphibiaWeb의 2026-04-01 분류 스냅샷과 대조하고, 별칭은 검색에 남겼습니다. 개구리 80, 도롱뇽 30, 무족영원 2종을 선정했습니다. 데이터의 개인·거래처 정보는 포함하지 않았습니다.
- 등각류: `isopod-research`의 hobby 데이터에서 `record_type=form`, `is_described=true`, `taxon_status=accepted`만 사용했습니다. `sp.`, 미기재 유통명, 지역형, 무늬 변이와 morph는 종 수에서 제외했습니다. 사육값은 원저자가 명시한 취미 사육자 합의 기본값이며 계통별 측정치가 아닙니다. 해안성 종류는 육상종과 다른 환경으로 표시했습니다.
- 거미: 공개된 종별 취미 사육 가이드 16개에서 학명과 온습도 수치 사실만 추출했습니다. 사이트 코드·사진·서술은 복제하지 않았고, 원 페이지 링크를 연결했습니다. 전문가 감수 자료로 표시하지 않았습니다.
- 식물: Plantfolio 데이터에서 식물의 첫 완전 이명법 학명을 추출하고 학명별로 한 항목만 선택했습니다. 단일 종 기록을 품종·속 일반 기록보다 우선했습니다. 실내·특수 재배 식물과 정원 관상 식물을 우선한 340종입니다. 속·품종군 기록에 연결한 대표 종은 일반 가이드임을 표시합니다. 재배 온도·빛·습도 등급·독성 분류·원산지 사실을 보존하고 한국어 안내를 작성했습니다. 정성적인 습도 등급을 숫자 범위로 임의 변환하지 않았습니다.

## 값의 검증 수준

현재 전체 목록은 **완전한 종별 사육 매뉴얼 845개가 아닙니다.** 기존 개별 요약, 종별 취미 가이드, 속·품종군 가이드, 취미 합의 기본값, 학명·사육 기록만 있는 기초 자료가 함께 있습니다. 각 상세 화면의 `careBasis`와 출처에 이를 표시했습니다.

- 새 파충류·양서류 기초 기록에는 확인되지 않은 온습도·성체 크기·난이도를 생성하지 않았습니다.
- 식물 원자료의 습도는 대부분 등급이므로 수치 비교 대상이 아닙니다.
- 등각류의 일반 기본값을 검증된 종별 합사 조건으로 계산하지 않습니다.
- 비교 자료가 부족하면 `적합`, `부적합` 대신 `자료가 부족해 적합성을 판단할 수 없어요`를 표시합니다.
- 국내 규정은 일괄 검증하지 않았으며 각 항목에 도입 전 확인 안내를 표시합니다.

## 재현과 갱신

앱 실행과 빌드에는 외부 API 호출이 필요하지 않습니다. 저장된 증거를 다시 컴파일하려면 Python 3을 사용합니다.

```bash
npm run catalog:build
npm test
npm run build
```

`evidence.json`은 선별한 사실의 스냅샷, `src/catalog/expanded.json`은 화면용 결과입니다. 숫자와 출처를 수정할 때는 스냅샷을 먼저 수정하고 재생성하세요. `scripts/extract-research.py`는 조사 시 사용한 공개 저장소 체크아웃을 다시 선별하는 개발용 도구이며 `VIVA_RESEARCH_ROOT` 아래 체크아웃을 요구합니다. 갱신 시 분류 변경과 라이선스를 다시 검토해야 하므로 자동 다운로드하지 않습니다. XLSX 파서는 `scripts/read_xlsx.py`에 포함되어 있습니다.

## 실제 사진·환경 정보 보완 및 분류 확장

2026-11-05 후속 작업에서 AI 이미지를 제거하고 Commons와 iNaturalist의 실제 사진을 수집했습니다. 출처·촬영자·라이선스는 `ASSETS.md`와 두 사진 매니페스트에 보존합니다.

- Plantfolio의 원문 careTips를 다시 읽어, 습도라는 문맥에 명시된 숫자 범위만 보완했습니다. 기존 상세 항목과 충돌하지 않는 식물 84종, 등각류 3종에 수치 근거를 표시했습니다. 원문 숫자를 찾지 못하면 비워 둡니다.
- `verified-care.json`: ReptiFiles 공식 care-sheets의 PDF를 읽어 학명이 일치한 58종의 구역별 온도, 습도, 최소 사육장, 성체 크기, 수명, 활동·먹이·서식 위치 등 확인 가능한 사실을 기록했습니다. 원 PDF·게시자의 서술과 사진은 배포하지 않습니다. PDF 숫자는 일부 오래된 자료이며 확인일이 원문 작성일을 뜻하지 않습니다.
- 가열 표면·공기·은신처 온도를 구분합니다. 온도 측정 역할이 다른 자료를 같은 값으로 단정하지 않습니다. 섭씨/화씨가 상충하거나 링크 제목과 PDF 종이 다른 사례는 `care-import-issues.json`에 기록하고 해당 값을 제외했습니다. 원문 내부의 생태 설명이 충돌하는 경우 태그를 제한했습니다.
- `verified-plant-traits.json`: NC Extension의 정확한 학명 페이지 222개에서 성장·번식·성숙 높이 등 제공되는 식물학적 사실만 보완했습니다. 단순히 페이지가 존재한다고 해서 모든 필드가 채워진 것은 아닙니다.
- `editorial-traits.json`: 식물의 활용 위치와 식재 예시입니다. NC의 성숙 높이·생육형태에서 도출한 공간 계획 태그도 표시합니다. 이는 동물과의 안전성이나 특정 사육장에 적합하다는 판정이 아닙니다.

식물 종류와 활용 위치는 배열이며, 동물 종류·서식 위치·기후도 독립된 배열입니다. `src/taxonomy.js`가 범주와 필터 조건을 정의합니다. 미등록 곤충·연체동물 등은 0종으로 표시하고 기존 거북류·무족영원류는 유지했습니다.

비바리움 역검색은 입력 사육장의 가로·깊이·높이와 종별 최소 규격, 성체 크기, 온습도, 서식 위치, 환기 자료, 온도 구배 자료를 대조합니다. 자료가 부족하면 별도 목록으로, 조건이 어긋나면 불일치로 분류합니다. 결과는 합사·건강·장비 성능·규제 확인을 대체하지 않는 검토 후보입니다. 식물 연동도 독성 보고·파손·섭식·조명·환기·농약 등 추가 검토가 필요한 후보만 의미합니다.

### 역검색 최소 규격의 최신 장 대조

- 크레스티드 게코는 PDF의 과거 규격 대신 최신 `crested-gecko-terrarium-size-cohabitation` 웹 장에 명시된 >12g 유체·성체 18×18×36 in 규격을 반영했습니다. 따라서 45×45×60cm 입력에 성체 사육장 조건을 충족한다고 표시하지 않습니다.
- 모닝 게코는 원문 장의 30×30×45cm, 미세 메시 환기·탈출 방지 설명을 연결했습니다. 원문 규격이 성체 2–3마리 그룹 예시라는 적용 범위를 함께 표시합니다. 개체수나 합사 안전성을 자동 확정하지 않습니다.
- 식물 높이가 확인되면 역검색에서 사육장 높이보다 큰 원자료 성숙 높이를 별도로 걸러 냅니다. 야외 성숙 높이는 실내 전정·왜화 결과를 보장하지 않습니다.

실제 사진 최종 집계: 704종. 사진의 라이선스·촬영자·원 출처·식별 기준은 사진 매니페스트와 상세 화면에 연결되어 있습니다. 남은 141종은 저작권이나 학명 일치를 확인하지 못해 사진을 대체하지 않았습니다. `coverage.json`에서 분류별 집계를 확인할 수 있습니다.

## 빈 항목 후속 보완

`enrichment-coverage.json`은 동일 ID의 보완 전후 데이터를 비교한 결과입니다. 748종의 기존 결측 필드에 값을 연결했으며, 동일 사실이 배지 설명 등 여러 필드에 표현될 수 있으므로 필드 수가 서로 다른 독립 사실의 수를 뜻하지 않습니다. 기존 845종과 비바리움 3유형, 사진과 즐겨찾기 ID는 유지했습니다.

| 파일 | 근거와 적용 범위 |
| --- | --- |
| `verified-plant-details.json` | 학명 또는 저장된 이명이 페이지 제목과 일치하는 NC Extension 222종의 짧은 구조화 사실. 야외 높이·폭과 광환경을 실내 적정 온습도로 환산하지 않음 |
| `verified-natural-history.json` | Animal Diversity Web 106종의 분류된 키워드와 조건부 수치. 원문 갱신일이 있으면 확인일과 별도 기록. 야생 기록을 사육 최소 규격·적정 수치로 사용하지 않음 |
| `verified-care-details.json` | 기존에 확보한 ReptiFiles 종별 PDF와 고정 커밋의 등각류·거미 취미 자료. 속·종군 PDF는 제외. PDF 해시 또는 원자료 커밋·항목을 통해 근거를 추적 |
| `reproduction-facts.json` | 파충류 275종의 생식 방식. 기존 분류 스냅샷의 종별 첫 절에서만 추출하며 다른 종을 논의하는 뒷부분을 해당 종의 특성으로 오인하지 않음 |
| `verified-amphibian-care.json` | Axolotl.org, Caudata Culture의 학명·이명과 실제 사육 문맥을 대조한 3종. 문장을 독립적으로 요약하고 출처와 HTML 해시 기록 |

본문·사진을 통째로 재배포하지 않습니다. 대학 자연사·원예 사이트는 짧은 구조화 사실과 출처만 사용했습니다. 등각류 MIT 조건과 기존 Plantfolio 파생 자료의 CC BY-NC-SA 조건은 계속 적용합니다. 취미 자료의 성체 크기나 수조 예시는 검증된 성체 몸길이·최소 사육장 필드로 자동 승격하지 않습니다. 아홀로틀의 성체 길이는 학명과 성체 문맥을 확인한 전문 자료의 범위를 별도로 기록했습니다.

수온으로 확인한 구간은 아홀로틀 16–18°C와 중국불배영원 수생 관리 14–20°C입니다. 두 종의 공기 습도는 만들어 넣지 않았습니다. 스페인갈비영원의 원문 상한 안내는 단일 경고값으로 기록하고 범위로 확장하지 않았습니다. 수온을 입력 공기 온도와 비교해 적합·부적합을 판정하지 않습니다. 평균 수명·최대 기록·성별, 성체·유생 조건도 합치지 않습니다.

식물 높이와 폭은 원문의 `Height`와 `Width` 표제를 나눠 변환합니다. 폭을 높이 범위에 포함시켜 사육장 적합성을 잘못 판단하지 않도록 회귀 검사를 추가했습니다. 독성뿐 아니라 접촉성 자극 보고도 식물 연동 시 위험 검토 대상으로 표시합니다.

재수집 도구는 `scripts/enrich-species-facts.py`입니다. 연구 도구 실행에만 `beautifulsoup4`가 필요하며 사이트 빌드·실행에는 필요하지 않습니다. 원문 HTML은 지정한 외부 캐시 폴더에만 보관합니다. `--cached-only`로 이미 내려받은 자료를 네트워크 요청 없이 다시 파싱할 수 있습니다. `scripts/extract-care-details.py`는 기존 PDF 텍스트 인덱스와 고정 커밋의 연구 체크아웃을 요구하며, `--pdf-records`와 `--research-root`로 경로를 지정합니다. 일반적인 앱 설치·빌드는 이 수집 도구를 실행하지 않습니다.

### 종별 사육 문헌 추가 보완

- `verified-care-articles.json`: Reptile Supply 및 Dubia의 공개 가이드에서 도입 문단에 학명·저장된 이명이 정확히 일치한 항목만 연결했습니다. 106종 중 90종은 개별 종 가이드, 16종은 여러 종 공통 참고입니다. 도입 문단 밖에서 먹이·비교 대상으로 언급된 학명으로 연결하지 않습니다. 판매업체의 입문 문헌이며 독립적인 전문기관 검증과 구분합니다. 게시일이 제공되면 확인일과 따로 표시합니다.
- `verified-caudata-care.json`: Caudata Culture 17종의 추가 참고 사항입니다. 종군 비교·변이군·저자 경험·과거 분류를 구분하며 숫자를 모든 종이나 계통에 이식하지 않습니다. 부화·유생·육상기·수중기와 계절별 관리 차이를 남깁니다.
- `additional-care-coverage.json`: 1차 보완 작업본과 비교해 동물 108종의 719개 필드를 추가 연결한 내역입니다. 같은 사실이 설명·주의 문구에 반복될 수 있어 독립 사실의 개수로 해석하지 않습니다. 식물 251종의 정성적 선호는 기존 자료를 화면에서 보여주는 개선이며 새로운 수치 사실로 집계하지 않습니다.

원문 HTML·사진은 재배포하지 않고 외부 임시 캐시에 보존했습니다. 저장 데이터는 짧은 수치 사실·조건·분류된 키워드와 독립적으로 작성한 한국어 참고 문구입니다. `scripts/collect-care-library.py`는 본문 학명 일치와 문헌 범위를 색인하고, `scripts/extract-article-care-facts.py`는 측정 구역·평균·최고·상한·하한·단계별 빈도를 나눠 읽습니다. 다른 숫자 앞의 'basking'이나 뒤 문장의 'peak'를 잘못 붙이지 않도록 실제 문헌 사례를 회귀 검사합니다. CGD가 간식으로 언급된 종은 주식으로 표시하지 않습니다.

예를 들어 화이트트리프로그 자료는 평균 습도 50%와 분무 등에 따른 최고 70%를 구분하므로 `[50,70]`이라는 범위를 만들지 않습니다. 숫자 범위가 없는 경우 구분된 정성·조건 정보를 표시하며 구간 비교는 보류합니다. 서늘한 구역의 측정 매체가 불분명하면 공기 온도로 단정하지 않습니다. 기존의 종별 ReptiFiles PDF 측정 프로필은 유지하고, 새 가이드의 규격 예시는 자동 적합 판정에 필요한 최소 규격으로 사용하지 않습니다.

미확인 필드는 상세 화면의 접을 수 있는 목록에 그대로 남아 있습니다. '채워졌다'는 집계는 실제 값이 추가된 필드만 계산하며 접힌 UI와 무관합니다. 기존 종·식별자·사진을 대체하거나 줄이지 않았습니다.
