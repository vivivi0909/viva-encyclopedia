# VIVA — 작은 생태계의 모든 것

식물·파충류·양서류·등각류 및 기타 절지류·비바리움을 탐색하는 한국어 반응형 정적 도감입니다. 앱 디자인과 코드는 독립 제작했으며, 대규모 자료는 인터넷의 공개 분류·사육·재배 자료를 선별해 출처와 라이선스를 표시했습니다.

| 구분 | 수록 수 | 분류 |
| --- | ---: | --- |
| 식물 | 340종 | 열대·관엽·양치·덩굴·다육·선인장·수생·정원 식물 등 |
| 파충류 | 293종 | 도마뱀 155 · 뱀 79 · 거북 59 |
| 양서류 | 112종 | 개구리 80 · 도롱뇽 30 · 무족영원 2 |
| 등각류·절지류 | 100종 | 등각류 84 · 거미 16 |
| 비바리움 | 3유형 | 열대형 · 건조형 · 팔루다리움 |

생물 845종과 비바리움 3유형, 총 848개 항목입니다. 같은 학명의 무늬 변이·유통명·아종을 별도 종으로 중복 집계하지 않습니다.

## 기능

- 이름·학명·별칭·분류·환경 검색과 난이도·환경·세부 분류·세부 유형 필터
- 식물, 파충류, 양서류, 등각류·절지류, 비바리움의 별도 탐색 메뉴
- 24/48/96개 단위 페이지 이동, 이름순·난이도순 정렬
- 자료 출처·확인일·근거 수준·관리 방법·주의 사항을 표시하는 상세정보
- 브라우저 localStorage에 저장하는 즐겨찾기 — 기존 항목 식별자 유지
- 온습도 공통 구간 비교 및 결측·미검증 자료에 대한 별도 안내
- 모바일 화면, 키보드 탐색, Escape로 대화상자 닫기, `/`로 검색

목록 전체가 완전한 종별 사육 매뉴얼은 아닙니다. 분류·사육 기록을 확인한 기초 자료와 취미 가이드·일반 기본값·기존 개별 관리 요약을 구별합니다. 확인하지 못한 온습도는 추정하지 않으며 자료가 부족하면 적합성을 확정하지 않습니다. 국제 거래 기록은 현행 국내 사육·수입 허가를 보장하지 않습니다. 조사·선정 기준은 [research/README.md](research/README.md)에 설명했습니다.

실제 촬영 사진만 사용하며 권리·학명 일치를 확인하지 못한 종은 사진 수집 대기로 표시합니다. AI 생성 이미지는 사용하지 않습니다.

## 로컬 실행

Node.js 24 LTS와 npm을 사용합니다. 서버 API·데이터베이스·키가 필요하지 않습니다.

```bash
cd /workspace/viva-encyclopedia
npm ci
npm run dev
```

개발 서버 주소를 로컬 브라우저로 엽니다. 클라우드에서는 제공되는 포트 연결 기능을 사용하세요.

```bash
npm test          # 종 수·중복·분류·출처·검색·페이지·결측 비교·저장 검증
npm run build    # dist/ 정적 사이트 생성
npm run preview  # 빌드 결과 확인
```

브라우저 검증에는 Chromium이 필요합니다. 이 환경의 `/usr/bin/chromium`을 기본 사용합니다. 다른 시스템에서는 Playwright Chromium 설치 후 실행 파일 경로를 지정하세요.

```bash
npx playwright install chromium
CHROMIUM_PATH=/path/to/chromium npm run test:e2e
CHROMIUM_PATH=/path/to/chromium npm run test:pages
```

먼저 `npm run build`를 실행하세요. 데스크톱 1440px·모바일 390px에서 총 22개 브라우저 검사를 수행합니다. Pages 검사는 `/viva-encyclopedia/` 하위 경로에서 실제 빌드 파일을 확인합니다. `test-results/`에 화면이 저장됩니다.

## 데이터와 출처 갱신

`research/evidence.json`은 조사에서 선별한 사실, `research/sources.json`은 출처 커밋·확인일·라이선스입니다. 앱은 빌드에 포함된 데이터를 사용하므로 외부 API 없이 동작합니다.

```bash
# 원자료 스냅샷을 검토·수정한 후 Python 3으로 화면용 자료 재생성
npm run catalog:build
npm test
npm run build
```

- `src/base-data.js`: 기존 개별 관리 항목·이미지 — 즐겨찾기 식별자 유지
- `src/catalog/expanded.json`: 확장 도감 데이터 (자동 생성)
- `src/data.js`: 상세 항목과 확장 자료를 학명 기준으로 합침
- `src/logic.js`: 검색·필터·페이지·비교·저장 처리
- `src/main.js`, `src/style.css`: 화면과 모바일 스타일
- `scripts/build-catalog.py`: 저장된 증거에서 도감 재생성
- `research/`: 조사 방법, 출처, 라이선스, 스냅샷
- `ASSETS.md`: 이미지 제작·표시 기준

Plantfolio에서 파생한 식물 자료는 **CC BY-NC-SA 4.0**입니다. 저작자 표시·비영리·동일조건 변경허락을 지켜야 합니다. 등각류 자료의 MIT 라이선스 및 상세 출처도 `research/`에 보존했습니다. 자료를 상업적으로 재배포하려면 이 조건을 먼저 검토하세요.

## GitHub에 반영하기

현재 파일을 작성했으며 자동 커밋·푸시·게시하지 않습니다. 원격에 변경이 추가되었다면 먼저 확인·통합하세요. 비어 있는 저장소에서 최초 반영하는 경우:

```bash
git add .
git commit -m "Expand VIVA to 845 species with taxonomy and source records"
git branch -M main
git push -u origin main
```

이미 `main`을 사용하는 경우에는 일반적인 커밋 후 푸시하면 됩니다.

## GitHub Pages 무료 배포

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. `main`에 푸시합니다. 이미 푸시했다면 **Actions → Deploy VIVA to GitHub Pages → Run workflow**를 실행합니다.
3. `build`와 `deploy` 성공 후 `https://kyrin090408-sudo.github.io/viva-encyclopedia/`에서 확인합니다.

워크플로는 Node 24에서 `npm ci`, 단위 테스트, 빌드 후 `dist`를 배포합니다. 상대 경로 `base: './'`로 저장소 하위 경로를 지원합니다. GitHub Free에서는 공개 저장소를 사용하세요. 이 작업은 GitHub Pages나 클라우드 환경을 자동 게시하지 않습니다.

## 저장과 개인정보

즐겨찾기는 기기·브라우저별로 저장되고 브라우저 데이터 삭제 시 사라집니다. 로그인·동기화·추적 분석을 사용하지 않습니다. 코드·자료·기존 이미지는 정적 파일로 제공되며 외부 출처는 링크를 선택할 때만 엽니다.

## 종류·환경 분류와 역검색

식물 도감에서 관엽, 양치·석송, 이끼, 덩굴·착생, 브로멜리아, 난초, 수생·반수생, 식충 식물의 8개 종류 카드를 선택합니다. 한 식물은 여러 종류·활용 위치·식재 태그에 속할 수 있습니다. 기존 정원 식물 등의 데이터는 전체 목록에서 그대로 찾을 수 있습니다.

동물 도감은 도마뱀, 뱀, 개구리·두꺼비, 도롱뇽·뉴트, 등각류, 거미·전갈, 곤충, 연체동물, 수생 무척추동물 및 기존 거북·무족영원 유형을 구분합니다. 아직 수록되지 않은 유형은 0종으로 표시합니다. 범주 배열과 유형 매핑을 확장해 새 종류를 추가할 수 있습니다.

서식 위치(수목·지상·지중·반수생·수생)와 기후(건조·반건조 등)는 별도 속성이며 여러 개를 동시에 표시·선택합니다. 같은 필터 내 선택은 OR, 서로 다른 필터 사이 조건은 AND입니다. 온습도 수치가 없는 종을 수치 조건에 맞는 것처럼 포함하지 않습니다.

환경 비교에서는 845개 드롭다운을 스크롤하지 않고 분류·세부 분류·이름·학명 검색 결과에서 고릅니다. 현재 도감 검색 결과와 카드의 비교 버튼에서도 바로 대상을 선택할 수 있습니다. 결과는 두 종의 출처와 함께 보여줍니다.

상단의 **역검색** 또는 메뉴의 **비바리움 역검색**에서 `45×45×60cm` 같은 사육장 크기와 온습도·서식 위치·기후·설비 조건을 입력합니다. 동물과 식물의 검토 후보, 자료 부족, 조건 불일치를 구분합니다. 최소 사육장 규격이 없는 종을 적합 판정하지 않으며 성체 크기·환기·가열 구역을 검토합니다. 검토 후보는 안전한 합사나 최종 사육 가능 판정이 아닙니다.

AI 생성 이미지는 사용하지 않습니다. 라이선스가 확인된 실제 사진과 출처만 연결하며, 사진이 없는 종은 수집 대기로 표시합니다. 실제 사진의 이용 조건과 촬영자는 상세 화면과 `ASSETS.md`에 있습니다. 동물 환경 및 식물 사실 보완 기록은 `research/README.md`를 참고하세요.

대용량 사진을 포함한 배포본은 `dist/`입니다. 다운로드용 HTML에서 원출처 사진을 인터넷으로 불러오는 경량 미리보기를 만들려면:

```bash
python3 scripts/export-preview.py --external-photos --output /workspace/viva-latest.html --zip-output /workspace/VIVA-preview.zip
```

이 미리보기에는 도감과 코드가 포함되며, 사진 표시는 인터넷 연결이 필요합니다. GitHub Pages에 배포하는 앱은 다운로드된 정적 사진을 같은 사이트에서 제공합니다.

채팅의 HTML 파일 미리보기에서 `<!doctype html>` 등 소스가 그대로 보이면 문서 미리보기로 열린 상태입니다. ZIP을 다운로드하고 PC에서 압축 해제한 뒤 `index.html`을 Chrome/Edge로 여세요. 모바일 파일 미리보기는 HTML 실행을 지원하지 않을 수 있습니다. 일반 웹 주소로 접속하려면 위 GitHub Pages 배포 절차가 필요하며, 미리보기 ZIP 생성은 사이트를 게시하지 않습니다.

현재 실제 사진은 생물 **704종**(파충류 254·양서류 89·등각류·절지류 82·식물 279)에 연결했습니다. 사진 141종은 재사용 권리와 종 일치가 확인된 파일을 확보하지 못해 수집 대기로 남겼습니다. 출처의 식별 등급을 기록하며, 모든 사진을 전문가가 별도로 재동정했다는 의미는 아닙니다. 최신 집계는 `research/coverage.json`입니다.
